## Overview
AI-Plant is a web-based AI system that detects plant diseases from leaf images and provides simple, farmer-friendly explanations, treatment guidance, and preventive measures in multiple languages. The project integrates a Teachable Machine-trained CNN model, Google Colab, LLMs (OpenAI/Gemini/Claude), and a Gradio interface.

---

## Features
- Detects diseases for Apple, Potato, and Tomato plants
- Provides **actionable, easy-to-understand explanations**
- Offers **treatment steps and preventive measures**
- Multilingual support
- Simple **browser-based interface** via Gradio

---

## Dataset
The dataset contains six classes of plant leaf images:
- Apple_Scab
- Apple_Healthy
- Potato_Early_Blight
- Potato_Healthy
- Tomato_Leaf_Mold
- Tomato_Healthy

**Training and Testing Folders:**
