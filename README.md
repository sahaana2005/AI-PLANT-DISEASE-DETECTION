# AI-Powered Plant Disease Detection 🌱

This project detects plant diseases from leaf images using Teachable Machine
and provides farmer-friendly explanations using Generative AI.

## Tools Used
- Teachable Machine
- TensorFlow
- Google Colab
- Gradio
- Gemini API

## Dataset
Six classes of plant leaf images:
Apple_Scab, Apple_Healthy, Potato_Early_Blight,
Potato_Healthy, Tomato_Leaf_Mold, Tomato_Healthy
